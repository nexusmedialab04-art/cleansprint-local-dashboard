# CleanSprint Dashboard — Open Source Hook Repository

This repository contains a lightweight, open-source demonstration version for local data processing using JavaScript and PapaParse.

## 🚀 What is this?
A technical proof of concept demonstrating how to build web browser-based desktop utilities without servers, complex installations, or command-line consoles.

## 🛠️ Tech Stack
* **HTML5 / Vanilla JavaScript (ES6+)**
* **Tailwind CSS** (via CDN)
* **PapaParse** (MIT License - Local CSV processing)

## 💻 How to test it locally?
1. Clone this repository or download the `index.html` file.
2. Double-click the `index.html` file.
3. It will open automatically in your default browser ready to run. Zero installations, zero server dependencies!
